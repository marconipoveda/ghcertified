---
title: "質問 146"
question: "Git と GitHub の違いは何ですか？"
---

> **詳細情報**: [Git vs GitHub](https://learn.microsoft.com/en-us/training/modules/intro-to-git/1-what-is-vc)
1. [x] Git は 1 つ以上のローカルブランチで作業し、リモートリポジトリに変更をプッシュできます。GitHub はリモートリポジトリとして機能し、ウェブサイトまたはコマンドラインツールを通じてアクセスします。
1. [ ] Git はクラウド上で実行される分散バージョン管理システム (DVCS) です。GitHub は Git 技術へのアクセスを提供するインターフェース層です。
1. [ ] Git は個々の貢献者によって使用されます。GitHub はグループの開発作業を簡素化するために複数の貢献者によって使用されます。
