---
title: "Pytanie 146"
question: "Jaka jest różnica między Git a GitHub?"
---

> **Więcej informacji**: [Git vs GitHub](https://learn.microsoft.com/en-us/training/modules/intro-to-git/1-what-is-vc)
1. [x] Git pozwala pracować z jedną lub większą liczbą lokalnych gałęzi i przesyłać zmiany do zdalnego repository. GitHub działa jako zdalny repository, do którego dostęp uzyskuje się za pośrednictwem strony internetowej lub narzędzi wiersza poleceń.
1. [ ] Git jest systemem rozproszonej kontroli wersji (DVCS), który działa w chmurze. GitHub to warstwa interfejsu, która zapewnia dostęp do technologii Git.
1. [ ] Git jest używany przez jednego współtwórcę. GitHub jest używany przez wielu współtwórców, aby uprościć pracę zespołową w ramach rozwoju oprogramowania.
